# Moje spotřeba paliva

## Obsah
- `index.html` – aplikace
- `manifest.json` a `sw.js` – instalace jako PWA a offline cache
- `icon.svg` – ikona

## Zveřejnění přes GitHub Pages
1. Přihlas se na github.com a vytvoř nový veřejný repozitář, například `moje-spotreba`.
2. Nahraj všechny čtyři soubory z této složky do kořenové složky repozitáře.
3. V repozitáři otevři Settings → Pages.
4. V části Build and deployment vyber Deploy from a branch, větev `main`, složku `/ (root)` a ulož.
5. Po zveřejnění otevři v telefonu v Chrome adresu ve tvaru `https://TVUJ-UCET.github.io/moje-spotreba/`.
6. V menu Chrome zvol „Přidat na plochu“ nebo „Instalovat aplikaci“.

## Důležité
Data se ukládají lokálně v prohlížeči telefonu. Používej Exportovat zálohu. Při vymazání dat prohlížeče nebo výměně telefonu je obnovíš přes Importovat zálohu.

Výchozí nastavení: 70 km do práce, 70 km zpět, 48 Kč/l. Každý záznam ukládá cenu platnou při jeho zadání.
